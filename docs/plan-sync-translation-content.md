# EasyRead Sync：翻译内容同步实施方案

## 1. 目标与已确认边界

本项目是独立 Zotero 插件，不修改原 `zotero-easyread` 插件或 EasyRead 安装程序。代码、测试与构建脚本位于项目根目录；`reference/` 只读。

目标链路：在电脑使用 EasyRead 完成全文翻译，在 Zotero 执行「同步翻译内容」，将 `EasyRead翻译` 存储附件交给 Zotero 的文件同步，再在 Android 官方 Zotero 内直接离线阅读。

已确认的产品决定：

- 手机优先，同时兼顾电脑和平板；当前移动端验收范围仅为 Android，不承诺 iOS。
- 未完成全文翻译的论文不同步。只译正文或指定页面，但未覆盖全文的任务，也不放行。
- 附件只含完整译文、公式、表格、插图和参考文献。不提供逐段原文按钮，不附带 EasyRead 阅读笔记、AI 讨论或聊天数据。
- 首版单向 EasyRead → Zotero，不回写手机批注、阅读进度或译文修改。
- 沿用现有坚果云 WebDAV 或 Zotero Storage 配置；插件不读取或管理云盘凭据。
- 原插件的阅读入口、发送 PDF 和独立笔记同步作为兼容功能保留，与翻译附件同步分开。

## 2. 实验证据与限制

用户指定论文 *A Multi-Agent System for Threat Detection and Correlation Using Large Language Models* 已完成 17 页翻译。实验核对了 EasyRead 与 Zotero 原 PDF 的完整 SHA-256，生成了纯译文静态 HTML，并经 Zotero 授权的本地 API 导入同一父条目。该实验文件约 1.27 MiB，包含 13 张图、8 个表格和 16 处渲染公式；用户已确认 Android 手机内阅读效果良好。

这些数字只属于该实验，不是一般文件大小或性能保证。实验不等同于完成插件的迁移、更新、批量操作和所有阅读样式验收。

已验证的关键约束：

1. EasyRead 原始离线 HTML 的正文最初为空，依赖脚本渲染。
2. Zotero 的快照阅读器限制文档脚本，直接挂载原始导出不能作为内置阅读方案。
3. 静态 HTML 可以把公式预先渲染为 KaTeX HTML/MathML，并内嵌字体、CSS 和图片，不需要在手机执行脚本。
4. Android 官方客户端源码存在 `text/html` 内置阅读路径。具体功能与性能仍须在目标版本验收。

此前文档关于「固定 1.4～2.2 MB」「导出零磁盘开销」「所有客户端原生可读」和「附带全部 EasyRead 交互」的承诺不再适用。

## 3. 生产与同步流程

```text
选择文献或 PDF
→ 校验父条目、附件权限与本地 PDF
→ 计算完整 SHA-256，查找 EasyRead 同一 PDF
→ 检查全文翻译与任务状态
→ GET /api/p/{id}/export?mobile=1
→ 只解析 pr-data JSON，读取内嵌图片
→ 再次核对来源、任务与译文快照
→ 使用插件自带的可信渲染代码生成完整静态 HTML
→ 校验附件身份、现有文件、批注及同步状态
→ 相同字节跳过；否则备份并创建或原地更新
→ 标记 to_upload，原子保存独立注册表
→ Zotero 按现有配置完成元数据和文件同步
```

不把导出的 HTML 插入 Zotero 的高权限文档，不执行服务返回的脚本，也不采用其 CSS。KaTeX 与 Markdown 代码随插件固定版本打包，不通过运行时下载执行。

### 3.1 全文守卫

`paper.translation.done_pages` 是页码数组，包含仅整理原文的 `en_pages`；`/api/library` 中同名字段是数量，不能混用。

导出前必须确认：

- `page_count` 是正整数。
- 页码是范围内的整数；去重后的 `done_pages − en_pages` 覆盖 `1..page_count`。
- 不存在排队、运行、等待确认、部分失败、失败或取消状态，也没有失败页。
- 正文块非空，源 PDF 的完整指纹匹配。

正常保留原文的参考文献条目不要求再译成中文。该例外不允许把未处理的参考文献页面当成已完成页面。

导出数据使用其自带的 paper 与 reader.edits；保存前再次读取状态与正文，发现内容变化则停止，避免把不一致的快照写入附件。

### 3.2 静态正文与阅读能力

正文支持标题、段落、列表、公式、表格、图和参考文献。用户对译文、图注、图内文字和列表项的修改优先于模型稿。辅助 `note` 块不混入论文正文。

图片必须为受支持的内嵌位图。缺图、不支持的块、无效表格、重复段落标识或无法渲染的公式会中止生成，不静默漏掉内容。最终 HTML 超过 32 MB 时停止挂载，避免大附件占用手机空间。

阅读优化使用不依赖脚本的能力：

- 单栏排版、桌面限宽。
- 折叠目录、语义化标题、普通锚点引用。
- 表格和长公式局部滚动，插图等比显示。
- 固定版本 KaTeX 与内嵌 WOFF2 字体。
- 深色、打印样式和键盘焦点样式。

搜索、目录侧栏、原生批注和阅读位置尽量复用 Zotero。不给 HTML 添加 AI 聊天、笔记编辑、独立阅读进度云同步或其他第二套阅读应用。

## 4. 附件身份、更新与失败恢复

### 4.1 识别与幂等

注册表映射键为 `libraryID:parentKey:完整 PDF SHA-256`。HTML 同时包含格式标记与源 PDF 指纹。恢复映射时检查父条目、文献库、存储类型、MIME 和内容标记，不只检查标题或标签。

- 首次挂载：`Zotero.Attachments.importFromFile`，`text/html`，`EasyRead` 标签。
- 重复同步：`relinkAttachmentFile`，保持同一附件 key 和当前 HTML 文件名。
- 生成字节与磁盘文件相同：不写附件、不修改时间戳、不制造上传任务。
- 注册表丢失：只接管唯一且来源标记相符的附件。
- 本地文件丢失：保留附件 key，恢复文件；不能仅凭注册表中的相同 Hash 跳过。
- 原 PDF 指纹变化：不能把另一份 PDF 的附件当成当前译文覆写。

单篇实验的旧文件没有来源标记。该文件只能在单选时经明确确认后接管，并先备份；批量操作不自动接管。

### 4.2 更新保护

元数据权限 `editable` 与文件权限 `filesEditable` 均须满足。待下载、强制下载、同步冲突中的附件不覆写。Zotero 同步进行中时先跳过；写入阶段通过原生暂停机制推迟新一轮同步，并在成功或失败后释放暂停。

若附件有原生批注或磁盘内容被人工修改：单选时显示默认拒绝的确认，批量时跳过并报告。更新不会删除批注，但文本或 DOM 变化可能使原生划线错位；本期不做自动重定位。

覆写前在 Profile 的 `easyread-zotero-sync-backups/` 保存上一份 HTML，每个附件只保留一份，不进入云端附件包。临时文件放在独立临时目录，最终清理。

文件成功而注册表保存失败时，回滚内存映射；下次同步可通过内容标记重新发现附件，避免重复创建。错误不被吞掉，批量汇总区分成功、无变化、跳过与失败。

### 4.3 文件同步

覆写后显式设置 `attachmentSyncState = "to_upload"` 并保存。条目元数据同步与文件同步不是同一件事；只验证 `saveTx()` 调用不足以证明 Android 已收到文件。

插件不手动调用坚果云接口，不改变用户自动同步设置。真实验收包括：桌面上传完成、手机同步元数据、重新下载更新、断网阅读。更新中的缓存行为和原生批注稳定性必须如实记录，不能仅凭模拟测试宣布完成。

## 5. 独立插件与迁移

| 对象 | 本项目 |
| --- | --- |
| 插件 ID | `easyread-zotero-sync@local.research` |
| 显示名称 | `EasyRead Sync` |
| 偏好前缀 | `extensions.easyread-zotero-sync.` |
| 注册表 | `easyread-zotero-sync.json` |
| 阅读笔记协议 | `zotero://easyread-sync/…` |

原插件的注册表、协议与更新源不被覆盖。连接目录和可执行文件路径可只读复用原设置，其他受管理状态不共享。

本项目 schema 2 保留 `attachments`、`notes`，新增 `views`。已有 schema 1 注册表先生成不覆盖旧快照的 `.bak`，再迁移并原子写入。未知 schema、损坏 JSON 或错误的映射结构会拒绝加载，不自动重置。

## 6. 验证与发布范围

核心测试在项目根目录运行：

```bash
node --test tests/core.test.cjs tests/compat.test.cjs
python -m unittest discover -s tests -p "test_*.py" -v
python build.py
```

验证分层：

1. 纯逻辑：全文守卫、迁移、稳定输出、用户修改、类型与资源安全。
2. 模拟宿主：创建、原地覆写、无变化、恢复、权限、批注、同步状态、失败清理。
3. 隔离 Zotero Profile：加载真实 XPI、真实存储附件与文件覆写，不触碰用户库。
4. 浏览器：关闭脚本、阻断网络，检查手机宽度下的正文、图表和公式。
5. Android 真机：原型已获用户通过；新插件产物与新增样式单独复核。

发布包仅包含本项目实现与必要许可证，不包含 `reference/`、论文、Profile、注册表、凭据、日志或测试产物。不操作用户桌面鼠标与键盘，不自动安装或覆盖用户正在使用的原插件。
